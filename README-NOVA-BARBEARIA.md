# Template de Barbearia para Revenda

Este pacote foi limpo para ser reutilizado em outra barbearia.

## Comece por aqui

1. Configure `js/config.js`.
2. Coloque as imagens em `assets/`.
3. Crie o usuário do proprietário no Supabase Authentication.
4. Abra o painel e personalize Configurações, Serviços, Barbeiros e Galeria.
5. Publique o site.
