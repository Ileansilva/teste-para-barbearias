COMO TROCAR A IDENTIDADE VISUAL
-------------------------------
1. LOGO:
   Substitua:
   assets/logo-barbearia.png

   Mantenha o mesmo nome para não precisar alterar os HTMLs.

2. FAVICON:
   Substitua:
   assets/favicon.png

3. SUA BARBEARIA:
   O proprietário pode trocar pela página:
   configuracoes-admin.html

4. CORES:
   Procure nos CSS principalmente:
   #d6a84f
   #f0c85a
   #f1d68c

   Essas cores representam o dourado principal.

5. TEXTOS DA PÁGINA INICIAL:
   Parte dos textos vem da tabela settings do Supabase.
   Outros textos fixos podem ser encontrados em index.html.

COMO CRIAR UMA CÓPIA PARA OUTRO CLIENTE
----------------------------------------
1. Crie um NOVO projeto Supabase.
2. Execute:
   supabase/schema.sql
3. Execute as migrations existentes na pasta supabase/.
4. Vá em:
   js/config.js
5. Troque:
   SUPABASE_URL
   SUPABASE_ANON_KEY
6. Troque:
   assets/logo-barbearia.png
   assets/favicon.png
7. Publique o projeto em outro repositório/domínio.
8. Crie o usuário administrador no Supabase Auth.
9. Entre no painel e configure:
   - nome
   - WhatsApp
   - Instagram
   - endereço
   - abertura
   - fechamento
   - intervalo
   - dias de trabalho
   - datas bloqueadas
   - regras de agendamento

O QUE NÃO PRECISA MUDAR AO REVENDER
-----------------------------------
Normalmente não é necessário alterar:
- lógica do booking.js
- lógica financeira
- lógica de comissões
- RPC de horários
- estrutura dos cards

Você só precisa alterar código se o novo cliente quiser
uma funcionalidade diferente.

IMPORTANTE SOBRE SUPABASE
-------------------------
Cada cliente deve ter seu próprio projeto Supabase se você
quiser vender instalações separadas.

Não reutilize banco de dados, usuários e credenciais da JK
Barbearia em outro cliente.

ATUALIZAÇÃO FINAL V15 — HORÁRIO DE FECHAMENTO
---------------------------------------------
A regra do agendamento foi consolidada para interpretar:

- ABERTURA = primeiro horário que pode ser escolhido.
- FECHAMENTO = último horário que pode ser escolhido.

Exemplo:
Abertura: 08:00
Fechamento: 19:00
Intervalo: 30 minutos

Horários gerados:
08:00, 08:30, 09:00 ... 18:30, 19:00.

A duração do serviço continua sendo usada para detectar conflito
com outros agendamentos do mesmo barbeiro.

Arquivo de referência:
supabase/booking_closing_time_fix_v15.sql

Na SUA BARBEARIA atual essa alteração já foi aplicada no Supabase.
Ao revender/criar outro banco, execute também essa migration.


CRM DE CLIENTES V16
-------------------
Página:
clientes-admin.html

Banco:
public.jk_customers

Ligação com agendamentos:
bookings.jk_customer_id

COMO FUNCIONA:
- Ao agendar, o telefone é procurado em jk_customers.
- Se o cliente existir, o agendamento é ligado ao cadastro.
- Se não existir, um cadastro básico é criado automaticamente.
- O proprietário pode completar data de nascimento e observações.

ANIVERSARIANTES:
O sistema compara mês/dia de birth_date com a data atual.
O botão WhatsApp abre uma mensagem pronta.

CLIENTES SEM RETORNO:
O sistema considera apenas agendamentos com status "concluido".
O proprietário escolhe o limite em dias (20, 30, 45, 60 ou outro).

MENSAGENS:
Use {nome} no texto de aniversário.
Use {nome} e {dias} no texto de recuperação.

Arquivos:
clientes-admin.html
js/customers.js
css/customers-v16.css
supabase/customers_crm_v16.sql


CAIXA E ENCAIXES V17
---------------------
PÁGINA CAIXA:
caixa-admin.html
js/cash.js
css/cash-v17.css

BANCO:
cash_registers
cash_movements

FUNCIONAMENTO:
- abra o caixa com o valor inicial;
- cortes concluídos durante o caixa entram automaticamente;
- Pix e Cartão contam como vendas;
- somente Dinheiro entra no cálculo do dinheiro físico;
- Entrada e Suprimento aumentam o caixa físico;
- Saída e Sangria reduzem o caixa físico;
- ao fechar, informe o dinheiro contado;
- se houver diferença, o sistema exige observação.

ENCAIXES / CLIENTE PRESENCIAL:
agendamentos-admin.html
js/walkins.js
css/walkins-v17.css

FILA:
O cliente aguarda sem ocupar um horário público.
Ao clicar em Iniciar, é criado um atendimento no horário real.

ENCAIXE:
O proprietário informa manualmente a data e horário.
Pode usar horário após o fechamento da agenda pública.
Ainda é impedido conflito com outro atendimento do barbeiro.

ORIGEM DO ATENDIMENTO:
online = agendado pelo site
encaixe = criado manualmente pelo proprietário
presencial = iniciado pela fila


EXCLUSÃO PROTEGIDA DE CAIXA V18
-------------------------------
- Somente caixa fechado pode ser excluído.
- Ao clicar em Excluir, o sistema pede e-mail e senha.
- O e-mail precisa ser o mesmo usuário logado no painel.
- A senha é validada novamente pelo Supabase Auth.
- Os atendimentos não são apagados.
- O vínculo cash_register_id dos atendimentos é removido.
- As movimentações manuais daquele caixa são removidas.
